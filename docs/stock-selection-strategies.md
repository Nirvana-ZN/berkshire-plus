## 1. 每周发现

### 1.1 流程

当前是“只发布尺子结果”模式：每层算完自动确认并进入下一层；人工覆盖、逐家裁决、手工确认的接口都返回 `DISCOVERY_RULE_ONLY`（409）。

1. **冻结批次**：每个自然周一个批次，冻结行情截面、行业分类、财务版本、三轨尺子版本。
2. **共同排雷**（三轨共用，只跑一次）：只保留沪深 A 股，排除北交所、ST/\*ST、退市整理；停牌超过 5 个交易日的记为数据不足；行业或基础字段缺失的记为数据不足。
3. **轨道门槛**：三轨各自独立判定，每家公司得到 `pass / drop / insufficient`（通过 / 淘汰 / 数据不足）之一。数据不足一律不算通过，也不会影响该公司在其他轨道的结果。最新年报距今超过 1 年的记为数据不足。
4. **候选竞争**：通过者按本轨排序键排序，同行业最多 2 家，每轨最多 15 家；行业未知的公司记为数据不足。
5. **深研**：候选竞争的入选者可直接启动深研，每个自然周最多 3 家不同公司，进入第 4 节的六关研究。旧的人工裁决层（逐家保留 / 排除、保留 3–5 家算成功）代码仍在，但规则模式下不会产生裁决记录。

三轨之间没有总分，同一家公司可以在不同轨道得到不同结论。

**现金转换率**（质量折价、GARP 共用，v4 改口径）：只取净利润为正的年份，算“经营现金流合计 ÷ 净利润合计”。v3 是逐年比值求平均，某一年利润很薄时会把均值抬高。

**周期行业名单**（质量折价的周期分支和 GARP 的排除名单共用，按申万二级行业精确匹配，13 个）：冶钢原料、普钢、特钢Ⅱ、煤炭开采、航运港口、装修建材、工业金属、小金属、能源金属、化学原料、养殖业、光伏设备、贵金属（v4 新增）。

### 1.2 优质折价（quality_discount）

**逻辑**：长期质量已被证明，当前估值相对**自身历史**明显打折。

非金融公司的门槛（按顺序判定，第一个不满足的门槛就是淘汰原因）：

| 维度 | 规则 |
|---|---|
| 上市年限 | ≥ 5 年 |
| 资本回报 | 近 10 年 ROE 均值 ≥ 12%，下行波动率 ≤ 0.25（v6，v5 及之前用变异系数；窗口排除上市前年份，至少 5 个观测） |
| ROE 趋势 | 近 3 年 ROE 均值 ≥ 10 年均值 × 0.8，防止用历史高回报掩盖正在下滑的公司（周期股和银行分支不查） |
| 盈利 | 近 5 年净利润全部为正，最新年度为正 |
| 净资产 | 最新净资产 > 0 |
| 现金流 | 近 5 年现金转换率 ≥ 1（需满 5 个净利润为正的年份） |
| 稀释 | 5 年股本增幅 ≤ 5% |
| 杠杆 | 最新一年带息债务 / 净资产 ≤ 1，利息覆盖 ≥ 3（v6 起带息债务 / 总资产 = 0 时免查利息覆盖） |
| 毛利率 | 5 年下滑 > 2 个百分点只作风险标记，不淘汰 |
| 存贷双高 | 货币资金 / 总资产 ≥ 20% 且带息债务 / 总资产 ≥ 20% 时淘汰（v5，v4 只作风险标记）；缺资产负债数据时不淘汰 |
| 折价 | PE 与 PB 都要满足：当前值处于自身 5 年月度序列的 30 分位以内，且 ≤ 5 年中位数 × 0.8（至少 60 个月度点） |
| 绝对估值（v5） | 盈利收益率（100 ÷ 当前 PE_TTM）≥ 十年国债收益率 + 3 个百分点。达不到时，PEG ≤ 1.5 也放行（PEG = PE ÷ (近 5 年扣非净利润年复合增速 × 100)，增速按 25% 封顶，口径同 GARP），案例卡记“PEG 放行”；没有 5 年扣非数据或增速不为正时不能走放行 |

- **国债收益率写在尺子里**：当前为 1.69%（中债 10 年期，2026-10-08），即 PE 上限约 21.3 倍。它是 `discovery/constants.py` 里的 `TREASURY_YIELD`（校准脚本和指数基金筛选共用），每次重新校准前手动更新，再随新尺子激活。
- **周期股分支**（上面的周期行业名单）：不查 ROE 趋势，也不查绝对估值门槛（存贷双高照查）；要求正常化盈利（5 年扣非净利润的中位数）> 0，且正常化 PE ≤ 15，避免用景气高点的利润算出低 PE。v4 起估值只看 PB 的历史分位与中位数折扣，不再同时要求 PE——周期股在盈利低谷时 PE 分位偏高，两个都要求会把几乎所有周期股挡掉（v3 基准 374 家只过 1 家），盈利端已经由正常化 PE 把关。周期股在景气高点 PE 最低，所以这里不用当前 PE；剩下的风险是 5 年窗口里景气年份占多数时中位数偏高，正常化 PE 会显得便宜，目前靠 PB 两道条件兜底，以后可以考虑把窗口拉长到 7–10 年。
- **银行分支**：5 年 ROE 均值 ≥ 10%，资本充足率 ≥ 12%，核心一级资本充足率 ≥ 9%，不良率 ≤ 2%；估值只看 PB（30 分位以内且 ≤ 中位数 × 0.8）。
- 保险和其他金融暂不支持，统一记为数据不足。
- **排序**：PE 历史分位从低到高 → ROE 下行波动率从低到高（v6） → 现金转换率从高到低。

### 1.3 深度价值（deep_value）

**逻辑**：价格极低，同时财务足够安全，能等到价值回归；并且要避开价值陷阱。

非金融公司：

| 维度 | 规则 |
|---|---|
| 便宜 | 正常化盈利（5 年扣非净利润中位数）> 0；正常化 PE ≤ 12 |
| 现金流 | 5 年累计自由现金流（经营现金流 − 资本开支）> 0 |
| 偿债 | 最新净债务 / 正常化自由现金流（5 年中位数）≤ 3；最新利息覆盖 ≥ 2（带息债务 / 总资产 = 0 时免查） |
| 陷阱排查 | 5 年股本增幅 ≤ 10%；5 年收入降幅 ≤ 20%；**最新年度扣非净利润较正常化盈利降幅 `earnings_decline` ≤ 30%（v7 新增，即最新扣非 ≥ 5 年中位数 × 0.7；防止 3 年景气高点把 5 年中位数锚定在高位、掩盖近两年盈利崩塌的价值陷阱；降幅在 0%–30% 之间但未触及淘汰线时记 `earnings_decline_worsening` 趋势恶化风险，27%–30% 记接近阈值风险）** |
| 利润纯度 | 近 3 年（v4，v3 只看最新一年）非经常性利润、资产减值、其他收益加处置收益，各自按“3 年合计 ÷ (\|正常化盈利\| × 3)”计算，分别不超过 30%、30%、20% |
| 存贷双高 | 规则同优质折价，淘汰（v5，v4 只作风险标记） |

- **金融分支（银行）**：PB 处于 30 分位以内且 ≤ 中位数 × 0.8；5 年 ROE 均值 ≥ 8%；不良率 5 年升幅 ≤ 0.2 个百分点；资本充足率 ≥ 12%，核心一级 ≥ 9%。
- **排序**：先把正常化 PE 按上限 12 均分四档（0–3、3–6、6–9、9–12 倍），档位从低到高 → PB 分位从低到高 → 净债务 / 自由现金流从低到高 → 正常化 PE 从低到高。这样同一档内比的是财务安全，而不是 PE 的零点几倍差距。非金融公司没有 PB 分位，档内实际直接按净债务排。

### 1.4 合理价成长（garp）

**逻辑**：增长真实、可持续、资本效率高，而且价格没有透支增长。只覆盖非金融公司；v4 起周期行业名单内的公司在 GARP 里记为不适用（数据不足），不跑任何门槛。

| 维度 | 规则（固定取最近 5 个年报，计算 4 个增长期） |
|---|---|
| 增长 | 收入年复合增长 ≥ 8%，扣非净利润年复合增长 ≥ 10% |
| 持续性 | 4 个增长期里，收入和利润各至少 3 期同比 ≥ 5% |
| 失速 | 最新一年增速比复合增速低的幅度 ≤ 10 个百分点 |
| 资本回报 | ROIC 5 年均值 ≥ 10%（没有 ROIC 时用 ROE 代替） |
| 增长质量 | 现金转换率 ≥ 0.8（v4，v3 为 1）；股本增幅 ≤ 5%；带息债务增量 / 收入 ≤ 20%；商誉增量 / 收入 ≤ 10%；并购现金支出 / 收入 ≤ 10%（v4 起并购现金净额为负时按 0 计，不再作废整家公司） |
| 利润率 | 毛利率、净利率 5 年下滑都 ≤ 2 个百分点 |
| 利润纯度 | 最新一年资产减值、非核心收益各自占扣非净利润 ≤ 20% |
| 估值 | PEG ≤ 1.5（增速按 25% 封顶，防止高增速把 PEG 算得过低）；PE ≤ 35 且处于自身历史 70 分位以内 |

- **排序**（v4）：利润持续增长期数从多到少 → PEG 从低到高 → 资本回报从高到低 → 现金转换率从高到低。v3 把现金转换率放在第一位，前几名都是现金转换率最高的公司，和“合理价成长”的本意不符。
- **风险标记**（v4，不淘汰）：用“市值 ÷ 当前 PE”反推的滚动 12 个月净利润超过最新年度扣非净利润的 1.5 倍时，标记 `ttm_earnings_above_deducted`。PEG 用的是含一次性项目的 TTM PE，除以的却是扣非增速，一次性收益会把 PEG 算低；9-29 快照里只有金山办公触发（2026Q1 归母净利润 21.95 亿，上年同期 4.03 亿）。
- **数据现状**：数据源没有可信的 ROIC，资本回报全部用 ROE 代替。v3 下全市场只有 1 家通过，主因是报表空白行被当成缺失（并购现金的可信覆盖只有约 4%）；v4 在数据层把“明细报表当期存在、但该行为空”记为 0，9-29 快照基准档 17 家通过。抽查 12 家通过公司 2021–2025 年的并购现金与商誉，与新浪财经报表逐项一致。

### 1.5 案例卡与反方风险

最终候选都会生成一张案例卡，内容包括：所属轨道、通过了哪些关键门槛、3–5 个关键指标、至少一条反方风险、缺失数据、与上周相比的变化。反方风险由固定规则产生（接近淘汰阈值、指标趋势恶化、行业专属风险、资产负债风险、证据缺失），不调用模型。系统结论只有“值得深研 / 观察 / 排除”三种，发现层不给买入建议。

## 2. 低估值榜 v5（已移除）

2026-10-09 删除了页面（`/cheap`）、接口和打分代码。它用第 3 节漏斗去劣，再要求 10 年 ROE 均值 ≥ 12%、5 年净现比 ≥ 1，按“10 年 ROE ÷ PE（或 PB）”打分，每个行业最多 2 家取前 30 家。

它的问题（也是做每周发现的原因）：把优质折价、深度价值、成长三种逻辑压成了一个分数，用的是横截面低估值而非自身历史，而且没有逐层确认，也没有周度冻结。

它留下的全市场名单抓取（`fetch_universe`）和 ST / 退市 / 停牌判定由每周发现继续使用，现在在 `market/universe.py`。

## 3. 去劣漏斗（旧版）

**淘汰规则**（按顺序判定，命中即淘汰）：

| 规则 | 豁免 |
|---|---|
| 10 年 ROE 均值 < 8% | 同时满足：上市不满 10 年，且 5 年毛利率 > 30%，且近 2 年经营现金流都为正 |
| 5 年累计自由现金流 < 0 | — |
| 利息覆盖 < 2（金融股不查） | — |
| 5 年毛利率 < 15% | ROE > 20%、净现比 > 1、且属于薄利模式（高周转薄利、会员、平台佣金） |
| 5 年经营现金流 / 净利润 < 0.7 | — |
| 10 年净利率 < 5% | 毛利率 > 30% 且净利率达标或在上升；或满足上一行的薄利模式豁免 |
| 5 年股本膨胀 > 20% 且不是并购造成的 | — |

**保留与决选**：通过者按市值、ROE、净现比从高到低排序，保留前 10 家并分成三类角色——

- 高确定性：ROE ≥ 15%，且市值排在前三分之一；
- 高弹性：市值排在后三分之一，或 PEG ≥ 1.5，或属于有色、煤炭、航运、证券；
- 其余为中弹性。

每类各选 1 家，共 3 家决选。

## 4. 深研六关 + 价格带（研究层）

这一层不是选股，而是对入选公司做买入决策，由模型按固定提示词产出、代码校验结构：

- **六关 Checklist**：能力圈、好生意、护城河、管理层、安全边际、决策纪律。任一关失败，结论强制为“不通过”；有灰色关时“通过”会被降为“灰色地带”；现价高于价格带时“通过”会被改为“不通过”。
- **镜子测试**：用 5 句话讲清投资理由。
- **价格带**：激进（便宜买）/ 稳健（合理买）/ 保守（停止加仓），或仅观察。
- **对照当前仓**：必须回答三问——该不该进来、钱从哪来、是否与已有持仓押同一逻辑。三问只记录，不影响结论。
- **结论**：通过 / 灰色地带 / 不通过。只有“通过”和“灰色地带”才进入观察池。
- 持仓侧另有“规则灯”：为每只股票设加仓上限价，现价触及即亮灯（`ledger/rules.py`）。

## 5. 共同原则

- **数据不足 ≠ 通过**：缺关键字段一律记为数据不足，不用代理值冒充（ROE 代替 ROIC 是明示的例外）。
- **尺子有账本**：改阈值必须激活新的尺子版本并写明改因；规则模式下不允许对单家公司做人工覆盖。
- **不凑数**：候选不够就如实标记，不为了凑满数量放宽门槛。
- **发现与研究分离**：发现层只决定值不值得花时间研究，买不买由研究层决定。

## 6. 芒格式评价

> “告诉我我会死在哪里，我就永远不去那个地方。”

**总评：这是一台很好的“排除机器”，但还不是一台“发现伟大企业的机器”。** 它把大部分蠢事挡在了门外，这已经胜过市场上九成的选股系统；但它筛出来的是“过去财务干净、现在比自己历史便宜”的公司，而芒格真正要找的是“未来二十年还会更好、现在价格不离谱”的公司。这两者有交集，但不是一回事。

### 6.1 做对了的

1. **逆向思考贯穿始终。** 共同排雷、去劣漏斗、利润纯度、存贷双高、稀释、并购现金——绝大多数门槛都在问“这家公司会怎么把我坑死”，而不是“它有多好”。这正是芒格的做法：先避开愚蠢，再谈聪明。
2. **“数据不足 ≠ 通过”。** 不知道就是不知道，不拿代理值自欺。芒格说“承认自己不知道，是智慧的开始”，系统把这句话写成了代码。
3. **不凑数、尺子有账本。** 候选不够就空着，改规则必须留下理由。这是在防备最常见的人性弱点——为了“有事可做”降低标准，以及事后篡改记忆。
4. **有检查清单。** 六关是飞行员式的清单，任一关失败就一票否决，不允许用其他关的高分去弥补。芒格一直推崇这种做法。
5. **三轨不加总分。** 不把苹果和橘子折算成一个分数，避免了“虚假的精确”。旧版低估值榜的教训已经吸取。
6. **优质折价轨最接近芒格本人。** 十年高且稳的 ROE、利润真的变成现金、不稀释、不加杠杆——这就是“以合理价格买好公司”的量化轮廓。

### 6.2 要挑的毛病

1. **后视镜开车。** 所有门槛都是过去 5–10 年的会计数字。高而稳的 ROE 是护城河留下的脚印，不是护城河本身；它说明不了未来十年这条护城河还在不在。真正决定成败的问题——定价权、竞争格局、行业会不会被技术颠覆——在筛选层完全没有，只在六关里交给模型读公开文本回答。模型读年报判断护城河和管理层，是整个系统最弱的一环，却承担了最重的判断。
2. **“比自己历史便宜”不等于便宜。** 优质折价轨只看 PE/PB 在自身 5 年历史里的分位，**非金融公司没有绝对估值上限**。如果一家公司过去 5 年恰好处在估值泡沫里（比如 2021 年前后的消费、医药），跌到 30 分位时可能依然很贵。芒格会问：按这个价格买下整家公司，所有者盈余收益率是多少？比十年国债高多少？这个问题 v4 之前系统没有问；v5 已补上（盈利收益率须高于十年国债 3 个百分点，见 1.2 节），但只覆盖非金融分支，银行和周期股仍靠各自的估值口径。
3. **深度价值轨是格雷厄姆，不是芒格。** 非金融分支不要求任何 ROE 或资本回报，只要便宜、能活下去、没有明显的陷阱。芒格早就离开了“捡烟蒂”：时间是平庸企业的敌人，价值回归可能永远不来。这条轨可以保留，但在深研排队时应该排在最后。
4. **GARP 的“增长”只是 5 年的外推。** 最近 5 个年报（2021–2025）恰好是一个特定的周期，5 年复合增长 ≥ 8% 更可能筛出周期受益者，而不是长期复利机器。v4 把周期行业排除掉是对的，但行业名单挡不住“非周期行业里的周期性增长”。另外用 ROE 代替 ROIC，会让高杠杆公司看起来比实际更好。
5. **拿锤子的人。** 系统在工程上极其精密：十进制运算精度上限设到 2048 位，几千行输入校验，每个窗口都有审计字段。可同时，ROIC 覆盖率是 0，并购现金可信覆盖率只有 4%，护城河靠模型读文本判断。精力大量花在“把数字算对”，而不是“算对的数字”。芒格说过：“宁要模糊的正确，不要精确的错误。”
6. **校准在隐性地凑数。** 原则写着“不凑数”，但三档校准和 GARP 修复方案都是用“通过多少家”来评价方案好坏的（例如现金转换率从 1 放宽到 0.8，通过数从 15 变成 19，被当作一项改进）。门槛应该由“什么样的公司值得拥有”来决定，而不是由“一周想看几家”来决定。如果本周只有 1 家合格，那就只看 1 家。
7. **机会成本只问不卡。** 芒格最常用的过滤器是：“这个新机会比我手上最好的那个更好吗？”研究层虽然要求对照当前仓回答三问，但答案不影响结论；发现层更是按绝对门槛逐轨判断。结果是任何过线的公司都有资格占用研究时间和仓位。
8. **没有问激励。** “给我看激励机制，我就告诉你结果。”A 股特有的风险——大股东高比例质押、频繁关联交易、国企管理层没有股权激励、实控人减持——都不在门槛里。存贷双高这个 A 股造假的经典信号也只作标记、不淘汰。
9. **节奏太勤。** 每周最多深研 3 家，一年就是一百多次深研。芒格一生只做了少数几个重大决定。周频扫描没问题，但“进入深研”的门槛应该远高于“通过筛选”。

### 6.3 如果只改几处

按性价比排序，每一条都尽量不增加新的基础设施：

1. **（v5 已做）优质折价加一个绝对估值锚**：例如扣非盈利收益率（1 / PE）至少比十年国债收益率高若干个百分点，或者直接设 PE 上限。只需在现有门槛里加一个阈值。
2. **让“对照当前仓”变成一关**：把已有的“该不该进来”升级为硬约束——说不清为什么比当前最好的持仓更好，结论最多是灰色地带，不能是通过。
3. **建一套反向案例集当回归测试**：放入已知的造假或暴雷公司（在它们出事前一年的数据），以及公认的长期复利公司。每次改尺子，都检查前者是否被挡住、后者是否能通过。这比看“通过多少家”更能说明门槛好不好，也是芒格式逆向思考最直接的落地方式。
4. **校准报告不再用通过数作为目标**，改为报告“被放进来的边缘公司长什么样”，由人判断它们是否值得拥有。
5. **把激励类红旗纳入排雷**：存贷双高 v5 已从“标记”改为“淘汰”（W41 数据下深度价值的格力电器因此出局）；大股东质押比例需要新接数据，项目里目前没有。

### 7.2 发现的问题（按严重程度）

1. **共同排雷没有覆盖率闸门，W40 只筛了 38% 的市场却照常完成。** W40 有 3003 家因 `price_date_mismatch` 记为数据不足（第 7 次拉取跑了约 17 小时，价格日期跨了交易日）。逐家判“数据不足”是对的，但批次层没有任何检查：轨道层的覆盖率闸门（`readiness_min` 0.8）的分母是“通过共同排雷的公司”，看不到上游已经丢了六成；规则模式下各层又自动确认（`confirm_waiting_layers`），没人看就一路跑完。W40 因此成了 W41 周对比的基准。修法：共同排雷层按“通过 + 淘汰”占全市场的比例设同样的闸门，不够就记 `data_not_ready`，不进入三轨。**2026-10-12 已修**：闸门 95%（`COMMON_READINESS_MIN`，正常周约 99%）；周对比跳过共同排雷覆盖率不足的批次，W39（72%，同样是 `price_date_mismatch`）和 W40（41%）因此不再作为基准，W41 暂无可比的上周。
2. **价格带方向没有定义，“太贵就不通过”的检查大多失效。** 提示词只说“给出激进 / 稳健 / 保守”，没说哪一档价格高。5 份非观望报告里有 4 份是“激进 > 稳健 > 保守”（把“激进”理解成愿意出的最高价），只有浙江鼎力是反过来的。`research/thesis.py` 的 `expensive_line` 遇到“保守价低于激进价”时直接返回空，于是这 4 份报告都没有做价格检查——包括唯一一份“通过”的益丰药房（现价 22.09，三档 22.5 / 20.0 / 17.5）。按模型自己的口径它没有超价，所以这次结论没有被改变，但这道防线目前形同虚设。修法：提示词写明“激进价 < 稳健价 < 保守价（停止加仓上限）”；`expensive_line` 遇到倒序时取最高一档作为上限，而不是放弃检查。
   - 全库统计比这 5 份更糟：65 份研究报告里 34 份给了价格带，23 份（约 68%）算不出上沿——除了倒序，还有“20.60–26.78（PE 10-13x）”这类区间写法，“取保守档最后一个数”会取到倍数或年份。
   - 2026-10-12 已修：提示词写明“激进价 < 稳健价 < 保守价”；上沿改取三档里出现的最高价格（不论写在哪一档），带“倍、x、年、%、股、PE、PB”的数字不算价格；事后簿在没有现价或算不出上沿时显示“无法对照”。修后只剩 3 份三档全空的报告算不出上沿。
3. **筛出来的公司，深研大多确认不了“好生意”。** 7 份深研里只有益丰药房通过；6 份的“好生意”或“护城河”至少一关是灰色，6 份的数据等级是最低的 C，景津装备因管理层（减持）和安全边际不通过。瓶颈不在候选数量，而在深研能拿到的信息：再多放几家进来，也只是多几份灰色报告。
4. **5 年估值窗口的起点正好在 2021 年 10 月。** 那是核心资产估值的顶部附近，所以“低于自身 30 分位、低于中位数 8 折”几乎对所有估值下行的股票都成立。W41 优质折价 12 家的绝对 PE 在 10–29 倍之间（珀莱雅 11.7 倍，5 年中位数 33.7；爱尔眼科 28.7 倍，5 年最高 120），并不离谱；但这个信号衡量的更多是“行业从 2021 年杀估值杀了多少”，而不是公司自身被错杀了多少。GARP 也一样：金山办公 28 倍对中位数 92 倍，兴齐眼药 16 倍对 42 倍。
5. **深度价值的名单每周翻动，主要是名额挤出，不是公司变差。** W41 有 47 家通过门槛，按 PE 档位只留 15 家；W40 入选、W41 消失的 12 家里，11 家是被名额挤出（`total_cap_exceeded`），例如泸州老窖、老板电器。周对比的“原因”字段又几乎总是“数据变化”：每家公司的数据指纹包含当周价格和 PE，每周必变，这个字段没有信息量。修法：周对比直接展示本周的淘汰原因（被挤出 / 门槛未过），删掉或重新定义“原因”字段。
6. **深度价值集中在基建链，行业上限挡不住。** W41 的 15 家里，中交设计、设计总院、浙江交科、中材国际 4 家属于工程设计和施工，另有大秦铁路、北新建材。它们分属不同的申万二级行业，“同行业最多 2 家”管不到同一主题。这类公司账上的“净现金”常常和大额应收、合同资产并存，而陷阱排查里没有应收类指标；目前数据层也没有应收账款、合同资产字段，要加这条需要先接数据。
7. **GARP 的风险标记不参与排序。** 第 2 名小商品城带 6 个恶化标记（增速放缓、商誉和并购增加、毛利率和净利率下滑），第 1 名史丹利带 3 个。这是设计选择，但案例卡上应该把标记数放在显眼位置。
8. **规则模式去掉了“写理由”的纪律。** 现在深研可以直接从候选竞争的名单启动，裁决表在三个批次里都是空的。人工唯一的过滤是“挑哪 3 家去深研”，而且挑选时不需要写理由。旧的裁决层代码还在，成了死代码。
9. **大量改动未提交。** v4、v5 改动和规则模式都只在工作区；数据库里激活的却是 v5 尺子。如果工作区被重置，HEAD 的代码只认 v3，三轨会全部变成“尺子未就绪”。根目录还有一批 `_tmp_*` 临时文件。

### 7.3 建议的处理顺序

1. 提交 v4、v5 与规则模式的改动。
2. ~~共同排雷加覆盖率闸门，并把 W40 标记为不可比较~~（2026-10-12 已修，见 7.2 第 1 条）。

## 8. 指数基金筛选（2026-10-13）

回答两个问题：哪个指数现在不贵，以及它的代表基金是否健康。分两步：

- **季度生成名单**：`uv run python -m scripts.build_index_fund_universe`（约 20 分钟），结果写进 `screen/index_fund_universe.json`，随代码提交。
- **日常刷新**：在指数基金页点“刷新数据”，只取名单里的指数和基金，约 2–3 分钟。只保留最近一次快照；不占全局任务锁（每周发现补数一跑十几个小时，共用锁会一直排队），同一时间只允许一次刷新。

### 8.1 名单怎么选

1. **候选**：东方财富全部场内 ETF（约 1600 只），加上天天基金里“指数型-股票 / 指数型-海外股票”的场外基金。去掉增强型、联接基金（买的就是对应 ETF，不会比 ETF 更好）和非 A 类份额，共约 2200 只。逐只读天天基金基本概况页，拿跟踪标的、费率、成立日期、净资产规模；债券、黄金、货币等由基金类型排除。
2. **每个指数一只代表**：按跟踪标的分组（2026-10-13：575 个指数）。代表须成立满 1 年、规模 ≥ 2 亿元、不是 Y 类份额，场内还要当日成交额 ≥ 1000 万元；满足的取年费率最低者，同费率取规模大的。有合格代表的指数 364 个。
3. **去掉走势重复的指数**：按跟踪该指数的全部基金规模合计从大到小，逐个加入名单；与已选指数近一年日收益相关系数 > 0.95 的视为重复，跳过并记下与谁重复。满 300 个为止；2026-10-13 版本合格候选（327 个）去重后选出 199 个：场内 154、场外 45；类别为主题 55、策略 29、行业 21、宽基 11、风格 1、海外 37、未分类 45。
4. **估值来源**：蛋卷 63 个指数优先（用蛋卷场外基金的跟踪标的对应）；其余按全称搜中证官网，用返回数据里的全称核对，一致才采用，并把 2016 年起的周度滚动 PE、最后一个 PE 及其日期（锚点）存进名单。2026-10-13 版本：蛋卷 28、中证 94；深证 / 国证系列和多数海外指数两边都没有（77 个），记为无估值来源。

去重只看近一年相关性，代价是一些常用指数会被合并：中证1000（与中证500 相关 0.965）、深证100（与创业板 0.972）、中证全指半导体（与科创50 0.971）。阈值是 `screen/index_funds.py` 的 `SIMILAR_CORRELATION`，调高会保留更多。被跳过的指数和原因都在名单文件的 `skipped` 里。

**中证限流**：中证官网的防火墙在约 150 次、间隔 1 秒的请求后会封 IP 数小时（返回拦截页）。生成名单时请求间隔 3 秒，遇到第一个 403 就停，已完成的进度留在文件里，过几小时用 `--valuation-only` 续跑（不重扫基金）。中证另有不受限的静态估值文件（oss 域名），但其中的 PE 与历史接口口径不同（沪深300 为 16.1，历史接口为 13.1），不能拼在一起算分位。

### 8.2 指数层

估值策略的完整说明（口径选择、推算方法、局限、读法）见 `docs/index-valuation-strategy.md`，这里只列规则。

- **口径**：按名称（及蛋卷标记）分三类——金融与资源周期类用 PB + 正常化 ROE（并显示达标最低 ROE 与可下滑空间），军工、新能源车、光伏、锂电、养殖等账面净资产解释力弱的强周期/高研发行业直接标“待复核”，其余用 PE；口径由项目决定，来源给不出所需指标时标“待复核”。
- **门槛**：估值收益率（PE 口径 100 ÷ PE；PB 口径正常化 ROE ÷ PB，正常化 ROE 取历史中位数与近 3 年均值的较低者）≥ 十年国债收益率 + 3 个百分点。这是估值利差，不是预期回报。国债收益率超过 30 天未更新、或指数属于海外分类时，暂停利差结论（改判“待复核”）。
- **中证来源**：刷新时不调用中证。当前 PE = 锚点 PE × 指数价格涨跌；推算值在门槛 ±15% 内、或锚点超过 91 天（13 周）的改判“待复核”（依据 `scripts/check_pe_proxy.py` 的回放）。
- **结论**：符合低估值筛选 → 不符合 → 待复核 → 数据不足；同组内按自身约 10 年估值分位从低到高。分位只是相对自身历史的位置，不能跨指数比较；页面显示估值覆盖率。

### 8.3 代表基金复核

每次刷新对名单里的代表基金再判一遍，按顺序判定，第一条不满足即为结论：

| 门槛 | 规则 |
|---|---|
| 份额 | 场外 Y 类份额淘汰：只能在个人养老金账户买，而费率常是最低，不排除就会被选成代表 |
| 费率 | 必须有；管理费 + 托管费 + 销售服务费（名单生成时冻结） |
| 成立 | ≥ 1 年 |
| 跟踪误差 | 必须有，且 ≤ 3%（天天基金跟踪误差页，每次刷新现取） |
| 规模 | ≥ 2 亿元；场外用名单里冻结的上季度净资产，场内用当前市值 |
| 场内流动性 | 当日成交额 ≥ 1000 万元（只看一天，安静的交易日可能误伤） |
| 场内溢价 | 现价相对参考净值的溢价率 ≤ 1%；折价不限制，对买方有利 |

QDII 基金的跟踪误差常在 3% 以上（汇率与时差），代表基金是 QDII 的海外指数较常被这一条挡住。

阈值都在 `screen/index_funds.py` 顶部，改了直接生效，没有尺子账本。
