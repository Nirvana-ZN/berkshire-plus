# 论文闭环（最小）

日期：2026-08-31  
状态：待你看完规格再开工  
实现规格：`_bmad-output/implementation-artifacts/spec-论文闭环.md`

## 问题

审视问「买入论文还在吗」，但只引用该名称最新一份评估。评估没有身份、不会过期。半年前的通过和昨天的占位灰色，谁新用谁。

## 做法

方案 B：合格评估自动落一份**现行论文**。同一名称只有一份。审视只认这份，不认「最新评估」。

论文内容就是已有产物：镜子五句、价格带、研究日、所用股价、评估 id。不建假设清单、红线、健康度。

## 立与覆盖

结论为 `pass` 或 `gray`、镜子满五句、且不是数据不足占位句 → 写入或覆盖该名称现行论文。

- `fail` → 不立；若该名称已有现行论文则删除（最新否决使论文消失）。
- 占位灰色（「第 N 句无法完成」）→ 不立、不删。
- 评估任务失败 → 不改论文。
- 不回填历史评估。旧仓在重评合格前显示「无论文」。

## 过期（任一即过期，只改状态，不删正文）

1. 研究日起超过 90 个自然日。
2. 价格带不是观望，且现价低于保守带下沿（取 `conservative` 文本里第一个有限数字；解析不出则本条不触发）。
3. 价格带是观望，且有研究日股价，现价相对其偏离超过 15%。

过期价仍按原规则：该票单票动作为无法判断。过期价不拿来判价格带击穿。

## 审视

| 状态 | 单票 |
| --- | --- |
| 现行且未过期 | 引用现行论文（评估 id），不是短体检 |
| 无论文 | 短体检，文案含「无论文」 |
| 论文过期 | 短体检，文案含「论文过期」；仍给持有/加仓/减仓/卖出 |
| 过期价或该票模型失败 | 无法判断（原规则优先） |

## 界面

持仓表、观察池多一列：有效 / 过期 / 无论文。有效或过期可点开对应评估页。评估页在本份即现行论文时显示「已立为论文」或「已更新论文」。持仓表内不加 `<button>` / `<a>`。

## 不做

假设清单、红线、健康度、过期后自动重评、审视一键应用、改去劣、改记账、读 Desk。
