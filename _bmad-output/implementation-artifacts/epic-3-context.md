# Epic 3 Context: 一键审视

<!-- Compiled from planning artifacts. Edit freely. Regenerate with compile-epic-context if planning docs change. -->

## Goal

在持仓页对着当前仓做一轮纸面审视：每只现有持仓一条单票动作，外加 0–3 条能落到现金与目标仓位的组合建议。有最近 Checklist 必须引用；没有则短体检（不是六关）。建议可再打开，即为本轮写下的决定；不记账、不改目标、不下单。没有审视，每周看仓仍停在「看完表」而写不下决定。

## Stories

- Story 3.1: 一键审视得到纸面决定

## Requirements & Constraints

- 持仓页一键触发。先刷新相关现价（失败则沿用缓存并标过期）；再对全部当前持仓做单票体检，并给出 0–3 条组合建议。关闭工作台再打开仍能看到该轮产物；无成交时该产物仍算本轮决定。没有「一键应用」改仓或改目标。
- 单票动作仅为持有 / 加仓 / 减仓 / 卖出，或无法判断；每票带理由，并对照规则灯与目标仓位。必须回答「买入论文还在吗」与「今天此价格还会买吗」；无法判断时明确说无法判断。有最近 Checklist / 决策备忘录则必须引用。无最近完整评估则短体检：两问、动作、一条理由、规则灯、实盘占比与目标；界面标明「短体检，非六关」。不得输出没有动作的两面讨好分析。未设目标的持仓仍进单票体检，标「无目标」，不参与偏差告警。有目标且实盘与目标绝对偏差大于 3 个百分点时给出再平衡提示，提示不下单。
- 缺现价（含过期价）或该票模型失败：该票只能是无法判断，不得给低置信的持有 / 加仓 / 减仓 / 卖出。本轮须标明含过期价；整轮审视仍完成。禁止编造行情或财务数字。
- 组合建议必须落到本轮持仓、现金与目标仓位。组合层看集中度、现金过多或过少、实盘 vs 目标、最近漏斗名单是否适合用现金或换仓买入。涉及新票时只考虑最近漏斗中结论为通过或灰色地带的名称；不通过的名称不得当「用现金买入」候选。每条含建议动作、涉及的名称、与现金或目标仓位的关系。禁止空泛评论。不做收益排行或「今日推荐」。
- 审视是重任务，占用已有全局锁；已有重任务再启动则被拒绝并看到当前任务类型。提交后能看到进行中，完成后看到产物或失败原因。未配置模型密钥：请求失败并指向设置，不生成假装完整的结论。现价刷新与手工价不占这把锁。未跑四大师仍须能完成审视。
- 产物可查询、可再次打开。中文 UI；主页面可见免责声明。建议停在纸面上。

## Technical Decisions

- **模块：** 审视落在 `review`。`review` 不 import `ledger`，只消费 `jobs` 注入的只读 `BookSnapshot`（名称、股数、成本、现金、目标、无目标标记、规则灯、现价、过期标记、现金保留名），并读最近评估与最近漏斗结果。必须读规则灯。只写 `portfolio_reviews`（及任务行）和 `reports/` 下 Markdown，不写成交 / 现金 / 目标 / 规则。出站经 `httpx2`；LLM 为 OpenAI 兼容 HTTP。
- **枚举与产物键：** 单票 `action` 为 `hold` / `add` / `cut` / `sell` / `unknown`；规则灯 `hit` / `clear` / `none`；漏斗结论 `pass` / `fail` / `gray`。审视 JSON 用 `positions[]`（每项 `name` `action` `reason` `actual_weight` `target_weight` `rule_light` `short_exam`）与最多 3 条 `portfolio_actions[]`（每条 `action` `names` `cash_or_target_link`）。禁止另起同义键名。UI 文案中文。
- **失败与锁：** 过期价或该票模型失败 → 该票 `action=unknown`，整轮仍完成。无密钥 → 400 并指向设置。第二任务 409，正文含当前任务类型。默认立即返回 job id，前端轮询；`sync=true` 仅测试。`GET /api/health` 含锁状态。
- **API：** 前缀 `/api`。至少 `POST /api/reviews`；进度走已有 jobs 查询。错误体 `error` / `code` / `detail`。路由在持仓页 `/positions`。
- **测试：** Fake LLM + Fake quotes，不打真模型或真行情。断言结构化字段入库、锁冲突、无密钥失败、过期价不得给出确定动作。

## UX & Interaction Patterns

- 入口在持仓页：一键审视 + 最近审视摘要。主路径是表格与结构化结论，不是对话窗口。
- 短体检必须在界面标明「短体检，非六关」。过期价与新价可区分；本轮含过期价须可见。
- 进行中与完成 / 失败可区分；失败原因可读。每个主页面可见「不构成投资建议」。无独立 UX 设计合同，交互以持仓页与纸面产物为准。

## Cross-Story Dependencies

- 依赖 Epic 1：当前持仓、目标仓位、规则灯、现价（含过期与手工价）、设置中的模型密钥。`BookSnapshot` 与持仓页共用同一只读投影。
- 依赖 Epic 2：全局重任务锁与进度轮询已落地；最近 Checklist 可供引用；最近漏斗的通过 / 灰色地带名称可供组合层考虑新票。本史诗不实现漏斗或评估。
- 本史诗仅一条故事；组合建议读最近漏斗，无漏斗时仍须完成单票审视，新票候选为空。
